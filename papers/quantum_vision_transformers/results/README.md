# Results

This folder exists to match the repository contribution template (`how_to_contribute.md`).

Recommended use:
- Put curated, publishable artifacts here (selected figures, tables, summaries).
- Leave raw run artifacts in `outdir/` (timestamped `run_YYYYMMDD-HHMMSS/` folders).

Note: this project historically committed reference assets under `figures/` and `reports/`.
New artifacts can live under `results/figures/` and `results/reports/` to follow the template.
