Task: one estimate of the paper's MMD² loss (Gaussian kernel σ = 3.0) for a Haar QCBM against 2000 boson-sampling data samples. Gurvits routes: K = 500 operators, Z = 5000 signs per estimate; sampler: 5000 samples per estimate; 8 repeats give the standard error (SE). Equal-precision time t* = t × (SE / ε)², ε = 0.01 × |L| (L exact from SLOS where it ran, else the JAX mean); exact SLOS: one evaluation. **JAX speedup = t*(route) / t*(JAX)**: > 1 means JAX is faster. Gradient: forward + backward time (JAX and SLOS only; the photonic_engines Gurvits estimator and sampler have no autograd). z = (mean − exact) / SE of the mean.
